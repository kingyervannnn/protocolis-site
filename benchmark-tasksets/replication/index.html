Benchmark replication kit

This kit holds the material behind the results published at protocolis.co and in the paper Solid-State Web Execution: Compiling Web Applications into Verified Operations for AI Agents. With it a reader can recompute every completion figure and run the same tasks on any system.

Download the whole kit (.zip)

Files

  • tasks.csvThe tasks: 20 short, 40 medium and 21 long, each with its start page and text. Short and medium tasks also carry the page a run must end on and the answers that are accepted.
  • outcomes.csvOne line for every counted run, 3,443 in all: the task, the system, the model, whether the system said it had finished, and whether the run was judged complete.
  • cells.csvThe 81 published cells: completed and attempted runs, cost, time and tokens per completed task.

How to read it

A cell is one system on one model on one task set. Its completion is the number of lines in outcomes.csv for that cell with judged_complete = yes, over the number of lines for that cell. Those two numbers are the completed and attempted columns of cells.csv, and they were checked against each other when this kit was built.

Short and medium tasks were run more than once per system, so a task can appear several times in a cell; attempt numbers them. Long tasks were run once.

Not every cell has the same number of long runs. The two rules in JUDGING.md explain why: tasks on a site that refused every system were replaced, and a single run that ended on a site's block page is left out of that system's count. The long tasks come from two public sets, WebVoyager and Mind2Web-Live; tasks.csv names the source of each.

Two Protocolis cells on the short set (Tools, frontier model) are shown on the site at 20 of 20, counted by the page check alone. Here and in the paper they are 19 of 20, under the full check that every other short and medium cell uses.

In two Protocolis cells on the medium set (Agents, strong model), both runs of one task ended on the site's robot check and were measured again; the second measurement is the one counted, as in the published record.

Every Protocolis run is a first visit: the system kept no memory of any site and has no site-specific code.

What is not here

The engine's source code and internal records are not published. The recorded runs are provided on request for replication. Access to the system itself, for running it on sites of your own choosing, can be requested at protocolis.co.

Built from the published record as it stood on 20 November 2026.

How each run was judged

One rule per task set. The same rule was applied to every system.

Short and medium tasks

A run is complete when all of these hold: the system finished; the page it ended on matches the pattern in final_page_must_match; that page shows an answer matching accepted_answer_pattern; and the answer the system gave also matches accepted_answer_pattern (both patterns are in tasks.csv). Every attempt is counted. On the medium set, a run whose evidence could not be captured is left out for every system, and the published record of the row says how many.

Long tasks

Judged after the run by WebJudge, from the Online-Mind2Web project, with its own prompts and its strict column. One judge model, gpt-5.6-luna at medium reasoning, ruled on every run of every system. The judge sees the run's actions and screenshots. It does not see the answer the system gave. A run in which the system itself reports that it was blocked is not complete.

The key points the judge checks were written once per task and used for every system. They are listed below.

Two rules decide which runs are counted. A task whose site refused every system (the two Amazon tasks) is left out for every system and replaced from a list fixed before any run. A single run that ended on a site's block page or robot check is left out of that system's count; the published record of the row names it.

On the frontier model, a long run that spent more than $2.00 on model calls is counted as not complete, for every system, and its spend stays in the cost. One run is affected: a Stagehand run (wv-ESPN--22) that the judge accepted.
