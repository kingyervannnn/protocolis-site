02compare

Feature for feature, it isn't close.

Browser Use comes two ways: as its own agent, which reads a screenshot every step, or as a browser driver underneath OpenAI's browser tools, run by OpenAI's tool runner. Protocolis is one engine with its own operations, verification and credential broker. It costs less than either on every model we have measured, and does thirteen things neither mode does.

That combination depends on two companies' release cycles, and no one can acquire it whole. Protocolis is one codebase: the engine, the tool layer, the credential broker and the patent filing transfer together.

03how it works

Compile. Operate. Verify.

Compile

On first contact, Protocolis compiles the application into operations an agent can call. No adapter is written and no workflow is taught.

Operate

The agent calls typed operations: search, filter, fill, select, submit. It reasons about the task, not about pixels or page structure. Protocolis handles the realities of live sites on its own: consent dialogs, pop-ups, frames, and modern bot protection.

Verify

Every operation reports what was done and what remains unproven. Passwords and keys are handled by a credential broker and never enter the model's context.

04demonstration

Same task. Same model. Head to head.

Protocolis against Browser Harness, Browser Use's newest tool: the same coding agent, model and prompt in both, each driving a fresh headless Chrome on one Mac, recorded in real time and unedited, played here at 4× speed; the clocks on screen show real time. The task: find the week's top Show HN on Hacker News and report its title, points, comments and submitter. Answers checked against Hacker News's own API and by Browser Use's judge model. Selected runs, one per model. Lean is a single engine setting, settle waits off, with every step still checked. Browser Harness is designed to drive your own signed-in Chrome; this task needs no sign-in.
