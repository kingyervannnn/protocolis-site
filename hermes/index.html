Hermes Agent, same model, same tasks, two browser tools

Upstream Hermes Agent in both panes, Grok 4.6 in both. Left: its stock Browser Use tool. Right: Protocolis as its browser tool. Five tasks, ordered by gap. Recorded unedited, played at 4x.

Hermes Agent at upstream commit d9f15af, unmodified, in both panes. Its only core browser tool is Browser Use's CLI; on the right that tool is replaced by Protocolis, which compiles the page into typed, verified operations, so a search or a count is one operation instead of a look-click-look loop.

Every race: Grok 4.6 in both arms, same prompt, started together, recorded unedited and played at 4x; answers checked against values fetched before the run; cost at Grok 4.6 list price ($2 in, $0.50 cached, $6 out per million tokens). Mac load under 15 during recording.

Hermes Protocolis: the agent makes the account, and never sees the password

A concept build of Hermes with Protocolis inside: a sessions panel beside the chat and a credential broker. One prompt: create an account on a site, keep the login in the broker, download a report. The broker generates the password and fills it; the model never receives it. 54 s, played at 4x.

What is on screen: the prompt goes in and three live web sessions appear in the panel; the broker creates the account with a password it generated and fills it; the agent reads the verification code from the mailbox; the report is downloaded and opened in the viewer; the session is pinned open. The vault shown is a demo vault.

Concept build on upstream Hermes Agent, shown here for discussion; not a Nous Research product.
