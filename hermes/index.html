Hermes Agent, same model, same task, two browser tools

Upstream Hermes Agent in both panes, Grok 4.6 in both. Left: its stock Browser Use tool. Right: Protocolis as its browser tool. The task is a count across every page of a category on a demo bookshop. Recorded unedited, played at 4x.

Hermes + Protocolis43.3 s · $0.11correct · 64k input tokens
Hermes + stock Browser Use tool78.2 s · $0.18correct · 125k input tokens

Hermes Agent at upstream commit d9f15af, unmodified, in both panes. Its only core browser tool is Browser Use's CLI; on the right that tool is replaced by Protocolis, which compiles the page into typed, verified operations, so the count across both pages ends in one extract instead of a page-by-page read.

Task: count the Mystery books under £20 across every page of books.toscrape.com. Both runs answered 10, which matches a count fetched before the run. Mac load under 15 during recording. Cost is at Grok 4.6 list price ($2 in, $0.50 cached, $6 out per million tokens); the run itself used a subscription.

Protocolis is not a Hermes fork. It is the layer under the agent: the same drop-in works for any agent loop that drives a browser.
